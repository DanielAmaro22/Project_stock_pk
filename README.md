# Project_stock_pk
¡Bienvenido a **Stock PK**! Esta es una aplicación web dinámica y ligera para la gestión, control y seguimiento de stock de artículos en tiempo real. Está desarrollada utilizando el framework **Flask** para Python y una base de datos **SQLite** gestionada mediante **SQLAlchemy**.

El proyecto permite dar de alta artículos mediante un identificador único (Número de artículo) junto con su stock correspondiente, listando todos los registros de forma ordenada directamente en la interfaz de usuario.
